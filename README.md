# One Emoji, One Smile

Exactly one emoji — the one that makes the judge smile: 😊

`main.ts` writes exactly `😊` (one emoji, no words, no punctuation) to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`), then reads it back to verify it matches exactly.
